# Android 记账应用

## 项目简介
本项目是一个基于 Java 的 Android 记账应用，用于记录日常消费支出。

## 主要功能
1. 添加消费记录
2. 显示消费列表
3. 删除消费记录
4. 数据持久化（SQLite）
5. 记账通知提醒
6. 后台任务演示

## 项目结构
  MainActivity.java - 主页面
  Transaction.java - 数据实体
  RecordDbHelper.java - 数据库
  TransactionAdapter.java - 列表适配器
  ExpenseViewModel.java - 视图模型
  BackgroundService.java - 后台服务

## 运行方式

1. 使用 Android Studio 打开项目；
2. 等待 Gradle 同步完成；
3. 连接模拟器或真实设备；
4. 点击 Run 运行项目。
